# hospital-management-system
A web-based Hospital Management System developed using Flask, Jinja2, Bootstrap, and SQLite to streamline hospital operations and improve the management of patients, doctors, appointments, and treatment records. The application provides role-based access for Admins, Doctors, and Patients, ensuring efficient coordination between healthcare providers and patients through a centralized platform.

The system simplifies appointment scheduling, doctor availability management, treatment record maintenance, and patient history tracking while preventing scheduling conflicts. It enables secure and organized access to medical information, helping hospitals deliver better healthcare services and maintain accurate records.

### Key Features
- Role-based authentication and authorization
- Doctor profile and availability management
- Appointment booking, rescheduling, and cancellation
- Appointment conflict prevention
- Patient treatment and medical history management
- Diagnosis, prescription, and doctor notes tracking
- Search doctors by specialization and availability
- Search patients and doctors by name or ID
- Administrative dashboard with hospital statistics


### Tech Stack
- **Backend:** Flask
- **Frontend:** HTML, CSS, Bootstrap, Jinja2
- **Database:** SQLite

This project was developed as a full-stack web application focused on digitizing hospital operations, improving healthcare workflow efficiency, and providing a seamless experience for administrators, doctors, and patients.
